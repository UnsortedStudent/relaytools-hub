Option 1: Drag-and-Drop to Cloudflare Pages (2 Minutes, $0/Month)

Cloudflare Pages gives you unlimited bandwidth, free automatic HTTPS, a fast global CDN, and automatically applies our security _headers file — no credit card required.

  1. Go to dash.cloudflare.com ↗ and create a free account (or sign in).
  2. In the left sidebar, click Workers & Pages → click Create → select the Pages tab → click Upload assets (Direct Upload).
  3. Give your site a project name such as relaytools. Your live free URL will become https://relaytools.pages.dev.
  4. Open Windows File Explorer to web_hub\public, drag the entire public folder into Cloudflare’s upload box, and click Deploy site.
  5. Within ~15 seconds your site is live! Open your new URL and check /, /catalog.html, /mcp-guide.html, and /sitemap.xml.
Pro Tip (Optional 1-Line URL Sync): If your live Cloudflare URL is different from https://unsortedstudent.github.io/relaytools-hub, run this single command locally to update sitemap.xml, robots.txt, and canonical SEO links, then drag-and-drop web_hub/public one more time:

Option 2A • Auto-Updates on Git Push

Cloudflare Pages + GitHub

Ideal if you want your site to auto-republish every time you add new tools or update Actor statuses.

  1. Create a free public GitHub repository (e.g., relaytools-hub) and copy web_hub/GITHUB_SHOWCASE_README.md as the repo’s root README.md for bonus developer discovery!
  2. Push web_hub/ using the commands below.
  3. In Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git.
  4. Select your repo, leave Build command blank, set Build output directory to web_hub/public, and click Save and Deploy.

git push -u origin main
Option 2B • 100% Inside GitHub

GitHub Pages ($0/Month Alternative)

Prefer hosting right on GitHub with zero extra accounts?

  1. Create a public repo on github.com/new ↗ and upload the contents of web_hub/public/ into a docs/ folder (or the repo root).
  2. Open your repository → click Settings → click Pages in the left sidebar.
  3. Under Build and deployment, set Source = Deploy from a branch, Branch = main, Folder = /docs (or / (root)), and click Save.
  4. Wait ~60 seconds and refresh the Pages screen — GitHub will display your live HTTPS URL (https://username.github.io/repo-name/).
  5. Run build_hub.py --base-url https://username.github.io/repo-name so sitemap.xml matches your exact GitHub Pages address.
Free Organic Search Traffic (5 Minutes)

Submit Your Sitemap to Google & Bing So Free Traffic Starts Flowing

Every tool page targets high-intent developer, security, and compliance searches (like SPF 10-lookup checker, CVSS v3.1 calculator, DOI to BibTeX, and AI robots.txt generator). Submitting your sitemap tells search engines to index all 16 pages immediately instead of waiting weeks.

1. Google Search Console

  1. Visit search.google.com/search-console ↗ and click Add property.
  2. Choose URL prefix and paste your live site URL (e.g., https://relaytools.pages.dev).
  3. Verify ownership using the quick HTML file upload or HTML meta tag method (Cloudflare DNS also verifies in 1 click if you connect a custom domain).
  4. Click Sitemaps in the left menu, type sitemap.xml, and click Submit.
  5. Use the top URL Inspection bar to click Request Indexing on your homepage and top 3 tools (email-auth-checker.html, dmarc-spf-generator.html, cvss-security-headers-tool.html).

2. Bing Webmaster Tools (1-Click Import!)

  1. Visit bing.com/webmasters ↗ and sign in with your Google account.
  2. Click Import your sites from Google Search Console — Bing automatically verifies your site and imports your sitemap.xml in one click!
  3. Why this matters: Bing’s search index also feeds DuckDuckGo, Yahoo, Ecosia, Microsoft Copilot, and ChatGPT web search.
  4. Bonus free traffic: Add your live RelayTools Hub URL to your Apify creator profile ↗ bio and your GitHub showcase repository’s Website field!
